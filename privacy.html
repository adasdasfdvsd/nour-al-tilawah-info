Privacy policy · Updated 24 October 2026

How this tool uses data

This policy covers Nour Al Tilawah Quran Publisher, a personal publishing tool operated by the owner of the Nour Al Tilawah channel.

Google and YouTube data

The tool uses OAuth authorization to access the operator’s YouTube channel identifier and the identifiers, titles, publication schedules, visibility and processing status of videos it manages. It uploads video files, thumbnails, titles and descriptions supplied or generated for that channel. It does not request access to Gmail, Google Drive or Google Contacts.

Purpose and sharing

Data is used to verify the destination channel, publish Quran videos in order, avoid duplicate uploads and monitor publication. Google/YouTube receives uploaded media and metadata. GitHub Actions processes the publishing tasks. The operator’s configured Telegram chat receives video titles, links, scheduled times and operational alerts, including links to Actions runs. Notification metadata can include links to videos that are still private. Private-video access remains controlled by YouTube.

Google user data is not sold, used for advertising, or used to train generalized AI or machine-learning models. The application’s use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

Storage and retention

OAuth credentials are stored as encrypted GitHub Actions secrets in a separate private repository, and are provided to authorized jobs when needed. Publication records and video identifiers are stored in that private repository to preserve progress and prevent duplicate publication. Run logs contain operational metadata; failed upload result artifacts, when produced, are retained for seven days. GitHub retains logs according to the repository’s retention settings. Rendered media is processed on temporary runners and uploaded to YouTube. Telegram retains delivered messages under its own settings.

Publication records are retained while this automation remains in use. The operator can remove records, logs, secrets, Telegram messages and uploaded videos through the respective services. Copies may remain subject to those services’ backup and retention policies.

Control and revocation

The owner can stop future automation in the private repository and revoke the application’s access from Google Account connections. Revocation stops future authorized API access; it does not delete existing videos or cancel schedules already stored by YouTube. Those are managed in YouTube Studio.

This public website

This is a static GitHub Pages website. It has no account login, analytics scripts or application cookies. GitHub may process technical request information to deliver and secure its hosting service under the GitHub privacy statement.

Contact

For questions about the tool or data removal, contact the operator through the Nour Al Tilawah YouTube channel. Do not post credentials or private account data in public comments.
